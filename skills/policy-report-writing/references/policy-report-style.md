# 정책연구보고서 문체·양식·방법론 참고 — 실측판

> **이 파일의 지위.** 정부·지자체가 실제로 납품받은 정책연구보고서 **632건의 원문**을 계량해 만든 참고서다.
> 규범(이렇게 써야 한다)이 아니라 **관측(실제로 이렇게 쓰여 있다)**이다. 발주처 지정 양식이 있으면 그쪽이 우선한다.
>
> **측정 방법 (재현 조건):** 행정안전부 PRISM(정책연구관리시스템) 공공데이터 API로 수집한 정책연구용역 DB([prism-db](https://github.com/parkjui92/prism-db))에 내려받아 텍스트 추출된 776건 중 본문 2만 자 이상 **632건**
> (중앙부처·처·청·위원회 428 / 지자체·교육청 204, 같은 과제의 PDF·HWP 중복은 1건으로 축약).
> 문체 지표는 표지·목차를 피해 **본문 중앙 40% 구간**만 표본했다. 빈도는 별도 표기가 없으면 **만 자당 출현수**다.
>
> **한계 3가지 — 수치를 인용하기 전에 읽을 것.**
> ① 장 구성 통계는 `제N장`·`Ⅰ.` 형식으로 장 제목을 단 보고서만 잡힌다. 목차 추출이 안 된 보고서가 많아 **채택률은 전부 과소계상**이다. 비율이 아니라 **순위와 배열**만 신뢰한다.
> ② 스캔본 PDF·표 중심 보고서는 본문이 빈약하게 추출된다. 표·그림이 많은 보고서일수록 표본에서 과소대표된다.
> ③ 이 수치는 2026년 9월 시점의 적재분이다. 갱신하지 않으므로 **연도 추세 주장에는 쓰지 않는다.**

## 1. 보고서 형태 — 실제 장 배열

관측된 지배적 골격은 **4단**이다. 학술논문의 「이론적 배경」 장이 있는 자리에 **현황·여건 분석**이 들어간다.

```
서론/개요  →  현황·여건 분석  →  대안·방안 설계  →  결론·제언
```

장 역할별 채택률(관측, 과소계상):

| 장 역할 | 채택률 | 대표 장 제목 |
|---|---:|---|
| 서론/개요 | 47% | 서론 · 연구개요 · 사업개요 · 추진배경 |
| 현황·여건 분석 | 34% | 지역현황 분석 · 환경분석 · 여건 진단 · 실태조사 |
| 대안·방안 설계 | 31% | 추진과제 · 기본구상 · 부문별 계획 · 개선방안 |
| 결론·제언 | 28% | 결론 · 결론 및 제언 · 정책제언 |
| 국내외 사례 | 13% | 해외사례 조사 · 주요국 동향 |
| 실행·로드맵 | 8% | 이행관리 및 환류 · 재정투자계획 · 추진체계 |
| 쟁점·문제 도출 | 3% | 과제발굴 · 시사점 도출 |
| **이론·문헌 검토** | **3%** | 선행연구 검토 · 이론적 배경 |

관측된 장 배열 상위 5종:

| 배열 | 문서수 |
|---|---:|
| 서론 → 현황·여건 → 대안·방안 → 결론·제언 | 19 |
| 서론 → 현황·여건 → 대안·방안 | 18 |
| 서론 → 현황·여건 → 결론·제언 | 15 |
| 현황·여건 → 대안·방안 → 실행·로드맵 | 14 |
| 서론 → 대안·방안 → 결론·제언 | 11 |

### ★「이론적 배경」 장에 관한 관측과 해석 — 오독 주의

**독립된 「이론적 배경」 장을 두는 보고서는 3%뿐이다.** 그러나 이것을 "선행연구를 안 본다"로 읽으면 틀린다.
같은 표본에서 **문헌조사·선행연구 검토를 연구방법으로 명시한 보고서는 32%**다. 즉 선행연구는 **읽되, 별도의 장으로
독립시키지 않고 서론의 배경이나 현황분석의 첫 절로 흡수**된다. 학술논문과 정책연구용역의 갈림길이 여기다.

> **이 킷과의 관계.** 이 킷의 표준 목차(`policy-research-design`)는 **학술형**(서론→이론적 배경→해외 동향→국내 현황→
> 정책 대안→우선순위·로드맵→제언→참고문헌)이다. 위 관측은 그것을 뒤집지 않는다. 두 양식은 독자가 다르다 — 학술형은
> 연구소·학계 독자와 인용 가능성을, 용역형은 발주처의 의사결정을 겨냥한다. **발주처 납품용이면 4단 골격에 가깝게
> (이론적 배경은 서론·현황분석에 흡수), 연구소 자체 발간물·이슈리포트면 학술형으로** 간다. 의도 확인서의 용도·독자로
> 정하고, 판단이 서지 않으면 분기 질문으로 올린다.

## 2. 양식 — 번호 체계·글머리·캡션

### 2-1. 계층 번호 (문서 3건 이상 사용 기준, 632건 중)

| 층위 | 표기 | 사용 문서수 |
|---|---|---:|
| 장 | `제1장` 또는 `Ⅰ.` | 155 / 92 |
| 절 | `1.` | 615 |
| 항 | `1.1` 또는 `1)` | 504 / 452 |
| 목 | `가.` `나.` `다.` | 352 |
| 열거 | `①②③` | 399 |

**지배적 조합:** `Ⅰ. 장` → `1. 절` → `1.1` 또는 `1)` → `가.` → `①`.
로마숫자 장과 `제N장`은 섞어 쓰지 않는다. 한 보고서 안에서 한 체계로 끝까지 간다.

### 2-2. 글머리 기호 — 실측 사용률

만 자당 출현수(중앙부처 / 지자체):

| 기호 | 중앙부처 | 지자체 | 관측된 역할 |
|---|---:|---:|---|
| `-` (하이픈) | 22.1 | 33.3 | **최다.** 최하위 실행 항목·부연 |
| `·` (가운뎃점) | 5.5 | 5.6 | 4레벨, 또는 나열 |
| `○` | 4.2 | 5.8 | 2레벨 주요 항목 |
| `①②③` | 5.0 | 3.5 | 병렬 열거(개수 고정) |
| `□` | 2.7 | 3.1 | 1레벨 대항목 |
| `◦` | 1.6 | 4.2 | ○의 변형 |
| `●` | 1.1 | 0.3 | 강조 항목 |
| `※` | 0.6 | 1.3 | 단서·주의 |

**부호의 역할을 문서 안에서 고정한다.** 같은 부호가 어떤 데선 대항목, 어떤 데선 부연이면 독자가 층위를 잃는다.
표준 3단: `□` 대항목 → `○` 주요 항목 → `-` 실행 항목. 4단이 필요하면 `·`를 더한다.

### 2-3. 표·그림 캡션

| 형식 | 문서수 |
|---|---:|
| `<표 1-1>` `<그림 1-1>` | 168 / 70 |
| `[표 1]` `[그림 1]` | 74 / 144 |
| `(표 1)` | 18 |

**꺾쇠 `< >`가 표의 다수파, 대괄호 `[ ]`가 그림의 다수파**다. 번호는 **장-일련(1-1, 1-2)**이 우세하다.
표 제목은 표 **위**, 그림 제목은 그림 **아래**. 출처는 캡션 아래 `자료: ` 로 단다.

## 3. 문체 — 두 모드가 공존한다

정책연구보고서의 문체는 하나가 아니다. **서술체와 개조식이 층위별로 갈린다.**

만 자당 종결형 출현수:

| 종결형 | 중앙부처 | 지자체 |
|---|---:|---:|
| 한다체 (~한다/된다/이다/있다) | 21.1 | 4.0 |
| 명사형 (~함/임/음/됨) | 20.1 | 21.1 |
| 과거형 (~하였다/했다) | 4.7 | 0.8 |
| 당위 (~할 필요가 있다/해야 한다) | 3.3 | 1.4 |
| 판단 유보 (~판단된다/보인다/사료된다) | 0.5 | 0.1 |

**읽는 법:**
- **중앙부처는 한다체와 개조식이 거의 1:1**이다. 서술 문단(한다체)과 요약·제언 블록(명사형)이 번갈아 나온다.
- **지자체는 개조식이 압도적**(명사형 21.1 vs 한다체 4.0)이다. 기본계획·용역 보고서일수록 통문장이 드물다.
- **판단 유보 표현은 거의 안 쓴다**(0.5/만 자 — 본문 1쪽을 1,000자로 잡으면 약 20쪽에 한 번꼴). "~로 사료된다", "~로 보인다"를 습관적으로 붙이면
  실제 보고서보다 훨씬 무른 글이 된다. 근거가 있으면 **단정하고, 없으면 범위를 밝혀 적는다.**

### 문장 길이 (실측, 중앙부처 78,150문장)

| 구간 | 길이 |
|---|---:|
| 25% | 61자 |
| **중앙값** | **88자** |
| 75% | 129자 |
| 90% | 198자 |

**중앙값 88자**가 기준선이다. 200자를 넘으면 상위 10%의 긴 문장이며, 대개 쪼갤 수 있다.
문단은 **4~10문장(중앙값 6)**이 관측 범위다.

### 종결형 3모드 — 어디에 무엇을 쓰나

| 모드 | 쓰는 자리 | 예 |
|---|---|---|
| **한다체** | 서론·현황분석의 서술 문단, 논증 | "…비중이 3년 연속 감소하였다." |
| **명사형(개조식)** | 요약, 제언, 추진과제, 표 안 | "…관리체계 강화 **필요**" |
| **당위형** | 제언의 결론부 | "…체계를 구축**해야 한다**" |

한 절 안에서 모드를 섞지 않는다. 개조식 블록에 통문장 한 줄이 끼면 그 줄이 튄다.

## 4. 개조식 3단 골격 — 실제 관측 패턴

정책연구보고서의 제언·방안 절은 대부분 이 골격이다.

```
◯(주제어)  진단 한 줄 + 처방 방향 … 필요
 - 구체 수단 1 … 필요
 - 구체 수단 2 … 강화
 - 구체 수단 3 … 제안
```

**핵심 장치 3가지:**
1. **`○` 항목 머리에 `(주제어)` 괄호 태그**를 단다 — `◯(기술개발·사업화)`, `◯(기반조성)`.
   독자가 목록을 훑을 때 괄호만 읽고 구조를 잡는다.
2. **`○`는 진단+방향, `-`는 수단**이다. 두 층의 성격이 다르다. `-`에 또 진단을 쓰면 층이 무너진다.
3. **종결은 명사형으로 끊는다** — `필요` / `요구` / `제안` / `강화` / `구축`.

### 논증 사슬 — 현황분석 문단의 골격

관측된 전형적 전개(교육부 성과분석 보고서 등):

```
현상 서술        …방식으로 운영되어 왔음
 ↓ 세부 분해     세부적으로, A는 …에, B는 …에 중점을 두고 운영되어 왔음
 ↓ 한계 지적     이러한 …는 개별 차원에서는 역할을 하나, … 연계성이 제한됨
 ↓ 귀결          이로 인해 … 구조적 한계가 존재함
 ↓ 전환          이에 본 분석에서는 … 유형별로 …
```

**"현상 → 분해 → 한계 → 귀결 → 그래서 본 연구는"**의 5박자다. 한계를 지적한 뒤 곧바로 본 연구의 착수 지점으로
넘어가는 마지막 전환이 이 장르의 특징이다. 한계만 나열하고 끝나면 용역 보고서가 아니라 비평문이 된다.

### 과제 도출의 근거 명시

과제·대안을 제시할 때 **선정 조건을 먼저 밝히는** 패턴이 관측된다.

```
● 과제는 …을 종합적으로 고려하여 도출하였으며, 다음 두 조건 중 하나 이상을 충족하도록 구성함
 ● 국내 미실시 또는 추진 미흡: …데이터 분석 결과, 해당 영역의 사업이 부재하거나 제한적임을 확인함
 ● 해외 사례 존재 또는 신규 제안: 미국 NSF, EU Horizon 등에서 관련 사업이 추진되고 있음
```

그리고 **면책문으로 닫는다**:

> "제안하는 과제는 …후보 과제 풀(Candidate Pool)의 성격을 가지며, 실제 사업 확정에는 별도 사전 타당성 검토·
> 예산협의·법제 정합성 분석이 필요함"

**제언의 구속력 범위를 스스로 한정하는 이 한 줄이 정책연구보고서의 표준 장치**다. 연구자의 제안과 발주처의 결정
사이 선을 긋는다. 빠뜨리면 보고서가 월권한다.

## 5. 연구방법 — 실제 채택률

632건 중 해당 방법을 본문에 명시한 문서 비율:

| 방법 | 채택률 | 비고 |
|---|---:|---|
| 사례분석·해외사례 | 64% | **최다.** 사실상 기본 장착 |
| 설문조사 | 56% | 표본설계·응답률 명시가 관례 |
| 전문가 자문회의·워크숍 | 48% | 차수·참석 구성 명시 |
| 통계분석·계량(회귀·패널 등) | 35% | |
| 빅데이터·텍스트마이닝·네트워크분석 | 35% | 최근 급증 층 |
| 문헌조사·선행연구 검토 | 32% | 장으로 독립하진 않음(§1 참조) |
| 현장실사·방문조사 | 28% | |
| SWOT | 22% | 지자체 기본계획에 집중 |
| 시나리오·수요예측 | 20% | |
| 심층인터뷰·FGI | 19% | |
| 법제·제도 분석 | 17% | |
| 경제성분석(B/C) | 16% | 시설·인프라 과제 |
| 델파이 | 6% | |
| AHP·계층분석 | 6% | 우선순위 도출 |

**설계 시 함의:** 정책연구는 **혼합방법이 기본**이다. 단일 방법으로 끝나는 보고서는 드물다.
전형적 조합은 **문헌·사례조사(맥락) + 설문 또는 인터뷰(실태) + 전문가 자문(타당성 검증)**이다.
우선순위를 매겨야 하면 AHP·델파이를 얹는다.

방법 서술은 **무엇을·몇 건·언제·누구에게**를 반드시 적는다. "전문가 자문을 실시하였다"만으로는 부족하고,
"3차에 걸쳐 산·학·연 전문가 12인 대상 자문회의를 실시하였다(2026.3~5.)"까지 간다.

| 단기·중기·장기 / 중장기 / 단계적으로 추진 | 68% |
| 추진체계 · 추진전략 · 추진방안 | 67% |
| 종합하면 · 살펴보면 · 정리하면 | 66% |
| 본 연구는 / 본 연구에서는 | 61% |
| 따라서 | 42% |
| ~할 것으로 기대된다 · 기여할 것 | 42% |
| 그러나 | 34% |
| 정책제언 · 정책적 함의 · 정책 시사점 | 31% |
| 한편 | 30% |
| 시사점을 도출 | 24% |

**이 표는 "쓰라"는 목록이 아니라 "이 장르의 기본 어휘"라는 관측이다.** 두 가지 규율이 붙는다.

1. **`본 보고서는`(16%)보다 `본 연구는`(61%)이 표준**이다. 자기지시는 한 표현으로 통일한다.
2. **`~할 것으로 기대된다`(42%)는 검증 없는 낙관의 온상**이다. 기대효과를 쓸 때는 기대의 **근거와 조건**을 함께
   적는다 — "…에 기여할 것으로 기대된다" 대신 "…가 전제될 경우 …까지 단축할 수 있다(A사례 기준)".

> **AI 문체와의 경계.** 위 표현들은 사람이 쓴 정부 보고서의 실제 어휘라 그 자체로 고칠 대상이 아니다. 다만 **한 문단에
> 접속 부사가 셋 이상 겹치거나**, 모든 절이 `이에 따라`로 시작하면 그건 장르가 아니라 관성이다. 빈도가 아니라
> **간격**을 본다. 글이 자기 얘기를 하는 문장("본 연구의 의의는"·"요구를 빠짐없이 반영")은 별개 문제다 —
> [clarity-rules.md](clarity-rules.md) §3.1.

## 7. 집필 전 자기점검 — 급소 7

1. **장 골격이 독자와 맞는가** — 발주처 납품이면 4단(현황→방안), 자체 발간물이면 학술형. §1 참조.
2. **부호의 역할이 문서 전체에서 고정됐는가** — `□`가 어떤 절에선 대항목, 어떤 절에선 부연이 아닌가.
3. **모드가 절 안에서 섞이지 않았는가** — 개조식 블록에 통문장, 서술 문단에 명사형 종결.
4. **문장 길이가 관측 범위 안인가** — 중앙값 88자가 기준선이다. 200자 넘는 문장이 반복되면 한 문장에 독립 정보가 여럿 겹쳤는지 본다. 거꾸로 짧은 문장을 잇달아 끊지도 않는다([clarity-rules.md](clarity-rules.md) §1).
5. **판단 유보가 과한가** — `사료된다`·`보인다`는 20쪽에 한 번 수준이 실제 관례다. 근거가 있으면 단정한다.
6. **제언에 면책문이 있는가** — 연구자의 제안과 발주처의 결정 사이 선을 그었는가. §4 참조.
7. **방법 서술에 무엇을·몇 건·언제·누구에게가 있는가** — "실시하였다"로 끝나지 않았는가.

## 8. 이 파일과 PRISM DB의 관계

이 문서는 **집필할 때마다 DB를 조회하지 않기 위해** 만든 요약이다. 문체·양식·형태·방법론·표현의 참조는 여기서 끝낸다.
DB를 직접 여는 것은 선행연구·발주 이력·계약금액을 **명시적으로** 조사할 때, 또는 특정 보고서의 원문 대목을 인용할 때로 한정한다.
상시 조회는 무관한 발주 목록을 근거에 섞는다. 도구와 함정(0건≠없음, PRISM≠NTIS, 공공누리 유형)은
[prism-db](https://github.com/parkjui92/prism-db) README에 있다.
