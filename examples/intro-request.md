# 정책연구보고서 첫 요청 예시

아래는 사용법을 보여주기 위한 **가상 업무**입니다. 실제 통계나 기관의 과업지시서가 아닙니다.
플러그인을 설치한 Claude Code에서 아래 내용을 붙여 넣고, 자신의 주제·보유 자료로 바꿔 쓰세요.

```text
지역 중소기업의 AI 활용 인력정책을 검토하는 보고서를 준비해줘.
독자는 지자체 정책 담당자이며, 교육지원·공동 인프라·전문인력 연계 방안을 비교하고 싶어.

먼저 연구 질문, 목차, 조사계획을 제안해줘.
자료가 없는 항목은 필요한 자료를 적어두고, 통계나 출처를 만들어 채우지 마.
목차를 확인한 뒤 조사와 집필을 진행하자.
최종 결과에는 근거 목록과 별도 검토 역할의 점검 기록도 함께 남겨줘.
```

첫 단계에서는 목차·연구 질문과 설계 점검 결과를 확인합니다. 본문 집필 전에 대상 지역,
비교할 대안, 확보할 자료를 조정하세요. 조사 이후에는 근거 목록에서 핵심 수치의 원문 위치를,
검수 이후에는 지적 사항과 수정 내역을 확인합니다.

이 예시는 작업 시작용 요청문이며 완성 보고서나 성능 평가 결과가 아닙니다.
